WaylandCraft 2.1.0 for Minecraft 1.21.1

Unofficial backport of WaylandCraft v2.1.0 from Minecraft 26.1.2 to Minecraft 1.21.1, available for NeoForge.

Launch Wayland and X11 apps (via xwayland-satellite), windows appear in the world
Window items (inventory / item frames / held in hand) and server-side item support
Full input: mouse, scroll, keyboard capture (G), hard capture (Alt+Q), relative mouse for 3D apps
Drag-and-drop, window manager (B), app launcher (V), mod settings
Install: drop the jar for your loader into mods. Linux only; a Flatpak launcher won't work, and NVIDIA users should set __GL_THREADED_OPTIMIZATIONS=0.
